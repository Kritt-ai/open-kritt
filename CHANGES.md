\## Major Modifications



The primary enhancement in this fork is a \*\*custom provider system\*\*, allowing users to integrate and use their own AI providers beyond the default upstream implementation.



\### ✨ Custom Provider System



Features include:



\- Custom provider registration

\- Custom model configuration

\- Provider-specific API credentials

\- Flexible provider management

\- Improved provider metadata handling



\### OpenAI-Compatible Harness



This fork also introduces an \*\*OpenAI-compatible provider harness\*\*, allowing any service implementing the OpenAI API specification to work seamlessly with the application.



Supported use cases include:



\- Self-hosted OpenAI-compatible endpoints

\- Local inference servers

\- Reverse proxies

\- Third-party OpenAI-compatible providers

\- Custom hosted models



without requiring changes to the core application.



\### Repository Improvements



\- Repository cleanup and reorganization

\- Removed unnecessary documentation and development artifacts

\- Improved project structure for future development
